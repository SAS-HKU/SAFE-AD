# PINN revision figures

These figures are generated by:

```powershell
python -m rl.plot_pinn_revision_evidence --device cpu
```

- `pinn_naturalistic_scene_conditioning`: scene source and PINN query on inD,
  rounD, and exiD. The latter two are zero-shot diagnostics, not calibrated
  cross-dataset validation.
- `pinn_highwayenv_fidelity_and_propagation`: held-out HighwayEnv field
  comparisons, independent inD future-occupancy validity, and the merge-policy
  descriptor-to-action propagation check.

`figure_manifest.json` records the accepted checkpoint hash, input summaries,
cache identifiers, and deterministic frame-selection rule. PDF is the
publication artifact; PNG is provided for repository preview.
